- Server (`src/AzureDesignStudio.Server/Program.cs`): `AzureAd` section (Instance/TenantId/ClientId/Audience/Scopes), `KeyVaultName`, `KeyVaultKeyName`, `ApplicationInsights:ConnectionString`, `Logging`, `AllowedHosts`. Non-DEBUG requires `KeyVaultName` (config or environment variable) or the host throws at startup.
- Server user secrets: `UserSecretsId` `a237ae84-fe59-44e2-8570-ed2f536ab4ed` in `src/AzureDesignStudio.Server/…csproj`
- Desktop (`src/AzureDesignStudio.Desktop/MauiProgram.cs`): `appsettings.json` copied to output via `Content Update="appsettings.json"`; keys `ServerUrl`, `ResourceRoot`, `AzureAd:Authority`, `AzureAd:ClientId`, `ServerScope`, `ArmServicePrincipal:TenantId`, `ArmServicePrincipal:ClientId`, `Logging`. The service-principal secret is read from Windows Credential Manager, never config (`src/AzureDesignStudio.Desktop/WindowsSecretStore.cs`).
- WASM (`src/AzureDesignStudio/Program.cs`): `wwwroot/appsettings.json` keys `AzureAd` (Authority/ClientId/ValidateAuthority), `ServerScope`, `ResourceRoot`, `Logging`; App Insights JS snippet + connection string live in `src/AzureDesignStudio/wwwroot/index.html`.
- No `.env` files exist anywhere in the repository.

**Build:**
- Versioning: `src/version.json` (`version` `1.0`, `cloudBuild.setVersionVariables=false`). `src/DockerBuild.ps1` runs `nbgv get-version -f json`, then `src/GenerateVersioningTargets.ps1` emits a transient `Directory.Build.targets`, builds the image, and deletes both files.
- Docker: `src/AzureDesignStudio.Server/Dockerfile` (build arg `BuildConfiguration`, default `Release`), `.dockerignore` at `src/.dockerignore`.
- CI: `.github/workflows/build.yml` builds `src/AzureDesignStudio.Server`, `src/AzureDesignStudio`, `src/AzureDesignStudio.Mcp`, `src/AzureDesignStudio.Core.Tests` (desktop deliberately excluded on `ubuntu-latest`), runs offline tests, then `DockerBuild.ps1`; a `codeql` job autobuilds C#.
- Release: `.github/workflows/publish.yml` publishes the WASM site zip, the Docker image, and a signed (optionally unsigned) Windows MSIX on `v*` tags.

**Source generation (in-repo codegen):**
- `src/AzureDesignStudio.SourceGeneration/AzureNodeDtoGenerator.cs` — incremental generator collecting `[MapToDto]`-annotated classes plus the `AzureNodeDto`, `AzureNodeProfile` and `AdsConstants` classes, then rendering `*.g.cs` from embedded Scriban templates `src/AzureDesignStudio.SourceGeneration/Templates/{AzureNodeDto,AzureNodeProfile,DataModelFactory}.scriban`.
- Wired in `src/AzureDesignStudio.Core/AzureDesignStudio.Core.csproj` as `<ProjectReference ... OutputItemType="Analyzer" ReferenceOutputAssembly="false" />`.
- ARM JSON is serialized at runtime from the committed POCOs in `src/AzureDesignStudio.AzureResources` (`DeploymentTemplate`, `ARMResourceBase`, `[AzureResource(type, apiVersion)]`). Those POCOs were produced offline by `ArmTypeGenerator` (`[GeneratedCode("ArmTypeGenerator", "0.1.8.0")]`, e.g. `src/AzureDesignStudio.AzureResources/Base/DeploymentTemplate.cs`); no generator tool ships in this repo, and the files are checked in as source.
