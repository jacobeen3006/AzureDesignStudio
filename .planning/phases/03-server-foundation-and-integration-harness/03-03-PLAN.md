<objective>
Move the database choice, the schema bootstrap and the crypto registration from compile-time branches to configuration, so Debug and Release behave identically and the test host can run on a temporary SQLite file.

Purpose: success criteria 1 (no `#if DEBUG` deciding the providers) and 3 (a test that creates a design writes to a temporary SQLite file) of the phase, and the `EnsureCreated` half of criterion 4. Every other success criterion in this phase was proven on an in-memory database; this plan changes what is under it. The tracer first: the same design round trip as plan 03-02, now selected by `Database:Provider` and landing in a unique file under the temp directory. Then the preprocessor conditionals go and the bootstrap moves into its own class, then `Crypto:Provider` gets its seam.

Output: `DatabaseProvider`, `DatabaseBootstrapper`, `CryptoProvider`, a `Program.cs` with no `#if`, Development launch profiles that select InMemory by configuration, and a harness factory with a per-host temp database and cleanup.
</objective>
