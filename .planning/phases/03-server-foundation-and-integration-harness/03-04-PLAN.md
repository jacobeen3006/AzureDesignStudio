<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| configuration -> provider selection | Operator-supplied provider and connection-string values decide which database the server opens |
| design-time tooling -> database | `dotnet ef` runs the factory on a developer machine; it must not need or leak credentials |
