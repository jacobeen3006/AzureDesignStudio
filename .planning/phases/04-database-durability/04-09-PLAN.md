<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-chosen file -> restore code | An arbitrary file from the file picker is opened by SQLite and eventually becomes the live database |
| staging folder -> startup | A staged candidate sits on disk between verification and the next launch |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-04-31 | Tampering / Elevation | Crafted database with triggers, views, virtual tables or foreign tables used as a restore candidate | high | mitigate | Verify the staged copy on a read-only connection with `trusted_schema` off; reject triggers, views, virtual tables and tables outside the model; `Full` integrity; migrate forward through EF only; the previous workspace is kept |
| T-04-32 | Tampering | Candidate swapped between verification and apply (TOCTOU) | medium | mitigate | Verification runs on the staging copy, the marker stores its SHA-256, and apply re-hashes before moving anything; a mismatch discards the candidate and leaves the live file untouched (tested) |
| T-04-33 | Tampering (data integrity) | Stale `-wal`/`-shm` replayed onto a restored file | high | mitigate | Live sidecars move with the old file; any sidecar left at the target path is deleted before the file opens; a test plants live WAL content and proves it is not replayed |
| T-04-34 | Denial of service / data loss | Restore replacing a workspace that cannot be recovered afterwards | high | mitigate | The previous workspace is moved to `workspace.pre-restore-<UTC>.db`, never deleted; an older restored file also gets its own premigration backup from the normal startup pipeline |
| T-04-35 | Information Disclosure | Staged candidate and backups readable by other users | medium | mitigate | Staging folder 0700 and candidate 0600 on Unix, profile ACL on Windows; staging is removed after apply or cancel |
| T-04-SC | Tampering | NuGet installs | high | accept | No package is added in this plan |
</threat_model>
