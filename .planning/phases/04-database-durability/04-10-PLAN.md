    New `UniqueIndexGuard.cs` (namespace `AzureDesignStudio.Workspace`): public sealed record `UniqueIndexSpec(string Table, string IndexName, IReadOnlyList<string> KeyColumns, string KeepOrderBy)`; public sealed record `UniqueIndexRepair(string Table, string IndexName, int DuplicateGroups, int RowsRemoved, string ReportPath)`; static class `UniqueIndexGuard` with `Specs` (two entries: `Designs` / `IX_Designs_Name` / `Name` / keep order `SavedAt DESC, rowid DESC`; `ChangeFeed` / `IX_ChangeFeed_TargetResourceId_ChangeKey` / `TargetResourceId, ChangeKey` / `ChangeTime DESC, rowid DESC`) and `Repair(SqliteConnection connection, IReadOnlyList<UniqueIndexSpec> specs, string reportDirectory, DateTimeOffset nowUtc, string requiredBackupPath)` returning the list of repairs that actually changed something. All identifiers come from the spec constants and are quoted with doubled double quotes; row values are only read and serialised, never concatenated into SQL.
