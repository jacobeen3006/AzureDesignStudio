<objective>
Let a developer work offline in DEBUG - register and exercise a subscription with no Key Vault and no Azure credentials - while Production refuses development keys and still requires Key Vault.

Purpose: Success Criterion 5 (CRED-01, CRED-02). Phase 3 left a one-value `KeyVault` seam in `CryptoProvider`; this plan adds the second value behind it.

Decisions implemented:
- D-10 (settled): an ICryptoService with a Data Protection DEBUG implementation selected by `Crypto:Provider`; Production refuses development keys and still requires Key Vault.
- D-13 (decided autonomously): ASP.NET Core Data Protection with a file-system key ring under the developer's profile, selected only when `Crypto:Provider` is the development value and the environment is not Production. Discretion taken: the provider is created standalone (`DataProtectionProvider.Create`) rather than through `AddDataProtection`, so it cannot change the application-wide key repository that antiforgery and cookies use.
- D-18: tests run on AdsServerFactory.

Output: `DevelopmentCryptoService`, the extended `CryptoProvider`, a Program.cs call that passes the environment, launch-profile settings and the tests.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-05-18 | Information disclosure | Development keys protecting production secrets | high | mitigate | CryptoProvider refuses Development in the Production environment before registering anything; the Production host test proves the host does not start; the Docker profile and checked-in settings never select it (guard test) |
| T-05-19 | Information disclosure | Development key ring readable on disk | medium | mitigate | Folder under the user profile, mode 0700 on Unix, DPAPI on Windows; the remaining plaintext-at-rest on macOS and Linux is documented (accepted residual for a developer-only mode) |
| T-05-20 | Tampering / integrity | A development blob decrypted by the vault service (or the reverse) as garbage | medium | mitigate | dev1: prefix; the vault path fails on it with a FormatException and the development path refuses unprefixed text, both mapped to the broken-link 404 |
| T-05-21 | Elevation of privilege | A launch profile or image enabling the development provider outside Development | high | mitigate | Guard test: only profiles that also set the Development environment may set the provider; the Docker profile and appsettings are checked |
| T-05-SC | Tampering | npm/pip/cargo installs | high | accept | No package is added; Data Protection ships in the shared framework |
